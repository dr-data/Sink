## 2026-04-28 - Cloudflare KV Inline Database Migrations
**Learning:** Performing inline database migrations (like `KV.put`) within read operations (GET requests) in Cloudflare KV environments leads to excessive write operations and significant performance degradation. This is particularly problematic in serverless environments where costs and speed are sensitive to unnecessary state modifications during reads.
**Action:** Avoid mutating state during read operations. If data structure migration is necessary, decouple the migration from the read path, ideally executing it via an offline script, a dedicated background migration endpoint, or updating entries upon subsequent write operations. Always maintain backward compatibility to handle unmigrated data in the read path without writing back.
